# v0.9.1 — KGJ Design 1.6.1 / 에디터 피드백

기존 웹 화면을 develop & improve할 때 사용할 에디터 피드백 가이드를 보강했습니다. `design-web-experience`에서 필요한 가이드를 선택하고, 독립 검토와 선택형 worksheet로 연결합니다.

- 도형 생성·이동·복제·삭제의 탄성 모션, 큰 그룹의 합성 이미지와 원본 간 전환을 설계합니다.
- 모달 퇴장의 현재 자세·불투명도·포커스·배경을 함께 점검하고, 중간 닫기·거절·복원을 다룹니다.
- 토스트의 대비·모바일 본문 폭·읽기 시간·자동 닫기와 명시 닫기·편집 도구 가림을 확인합니다.
- 작은 수정은 관련 동작만 검증하고, 대형 문서 부하 시험은 명시적 요청 또는 적용되는 프로젝트 계약에 따라 진행합니다. 사용자가 정한 opt-in 조건을 보존합니다.

젤리모션·색상·시간·임계값은 제품에 맞춰 선택하는 후보 패턴입니다. 모든 제품의 기본값으로 강제하지 않습니다. 이번 변경은 가이드·라우팅·문서이며, 스킬 13개·MCP 도구 14개·기존 토큰·DNA·Dictionary 스키마·기본 프롬프트·권한·외부 데이터 경로는 유지됩니다. 개인 데이터 이전은 필요하지 않습니다.

## 검증 범위

저장소 회귀·공개 소스 검사, 정확한 커밋의 ZIP 재현성, 격리 설치·MCP 읽기 호출, 합성 데이터의 업데이트·rollback을 각각 확인합니다. 결과와 최종 커밋은 GitHub Release의 검증 기록에 연결합니다. 안내 문서만으로 생성된 화면의 품질이나 모든 브라우저의 성능을 보장하지 않습니다.

이번 공개 소스 릴리스는 KGJ의 닫힌 15검사·3라운드·9.9 인증을 주장하지 않습니다. 기존 엄격한 인증 기준과 검증기는 유지합니다. 비공개 캡처·제품 소스·대화·작업 경로·Dictionary·실행 영수증은 공개 소스 패키지에서 제외합니다.

K-Tech Insight Radar 0.4.0, Canvas Web Experiences 1.7.0, Codex Daily Check 0.5.1은 유지됩니다. 기존 FORM / TEN 예시도 변경하지 않았습니다.
