# v0.11.0 — 디자인 후보 비교와 개발 중 재검토

KGJ Design 1.7.0은 UI R&D를 시작할 때 디자인 초안 4~5개와 관련 에셋 대안을 먼저 비교하도록 안내합니다. 디자이너, UI 디자이너, UX 디자이너, UI/UX 엔지니어, Product 디자이너 관점에서 각 20점씩 평가하고, 적격 후보 중 최고점 안을 적용합니다.

개인정보·에셋 권리·핵심 기능·접근성 문제가 있거나 근거가 부족한 안은 점수가 높아도 선정하지 않습니다. 동점은 비교 검증 전까지 보류합니다. 실제 검토 주체와 독립·순차 검토 여부를 기록하며, 역할 이름만으로 전문가가 참여했다고 표현하지 않습니다.

개발 중에는 부정적 검토 → 원인 가설과 R&D → 최소 개선 → 현재 변경 검증 → 재검토를 최대 3회 진행합니다. 실패 기록과 같은 작업 ID를 유지하고, 변경으로 낡은 근거는 다시 확인합니다. 한도에 도달해도 문제가 남으면 완료로 처리하지 않습니다.

새 템플릿과 읽기 전용 검사기는 파일 해시·필수 항목·점수 합계와 선정 결과를 확인합니다. 시각적 품질, 실제 렌더링, 권리 또는 독립 검토의 진실성을 인증하지 않습니다. 기존 출시 품질 점수와 3개 라운드, 모델 비교 벤치마크는 별도로 유지합니다.

공개본에는 일반 지침·빈 템플릿·검사기·합성 테스트만 포함합니다. 실제 디자인 패킷, 사용자 에셋·캡처, 개인 Dictionary와 메모리는 포함하지 않습니다. 데이터 스키마와 저장 경로는 바꾸지 않으며 K-Tech Radar 0.4.1, Canvas Web Experiences 1.7.0, Daily Check 0.6.0은 그대로입니다.

자세한 절차는 [후보 평가 가이드](../plugins/kgj-design/references/design-candidate-workflow.md)를 참고하세요.
