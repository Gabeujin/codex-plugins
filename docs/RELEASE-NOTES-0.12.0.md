# v0.12.0 — 작업 간 개인 디자인 인사이트 누적

KGJ Design 1.8.1은 디자인 작업의 피드백과 관찰 결과를 개인 Dictionary에 적재하고, 다음 작업의 디자인 선택에 활용합니다. 인사이트는 작업 지침과 분리해 보존합니다. 학습이 허용된 작업에서는 별도의 ‘기억해줘’ 요청 없이 적재하며, 저장 금지 요청은 따릅니다.

작업을 시작할 때 `prepare_personal_design`으로 프로젝트 인사이트를 읽고, 재사용할 근거가 생기면 `capture_design_insight`로 적재합니다. 기존 14개 도구를 유지하고 두 도구를 추가해 총 16개가 됩니다. 자동 호출은 활성 스킬과 에이전트가 작업 흐름을 수행하는 방식입니다.

기본 범위는 프로젝트 내부입니다. 여러 프로젝트에 적용할 취향은 사용자가 직접 밝힌 경우에만 별도로 확인해 저장합니다. 추정은 검토 전까지 적용하지 않으며, 정정·철회·재실행은 기존 revision·이력·중복 방지 규칙을 따릅니다. 읽기 호출은 기록을 만들지 않습니다.

개인 저장소는 설치 캐시 밖의 기존 Dictionary 1.0 형식과 위치를 사용합니다. 업데이트는 실제 기록을 초기화하거나 Codex 메모리를 가져오지 않습니다. 공개 패키지에는 일반 코드·지침·합성 예제만 포함하며, 실제 개인 기록·회사 업무 자료·메모리·계정 정보·로그·캡처는 포함하지 않습니다.

1.8.0 개발 후보는 보존하고, 정식 안내를 포함한 1.8.1을 새 버전으로 제공합니다. 데이터 변환은 필요하지 않습니다. K-Tech Radar 0.4.1, Canvas Web Experiences 1.7.0, Daily Check 0.6.0은 그대로입니다.

검증은 합성 데이터를 사용한 작업 간 저장·검색, 프로젝트 격리, 디자인 선택 로직과 기존 런타임 호환성을 다룹니다. 실제 모델의 디자인 품질 향상이나 모든 사용자 환경을 인증하지 않습니다. 사용 범위와 한계는 [개인 인사이트 안내](KGJ-PERSONAL-INSIGHTS.md)를 참고하세요.
