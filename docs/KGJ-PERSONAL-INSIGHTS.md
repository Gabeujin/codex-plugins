# KGJ Design의 개인 인사이트 누적

KGJ Design 1.8.1은 디자인 작업에서 얻은 피드백과 관찰 결과를 개인 저장소에 적재하고, 다음 작업의 디자인 선택에 다시 활용합니다. 기존 Dictionary1.0 저장 형식과 위치는 유지합니다.

1. 작업을 시작할 때 `prepare_personal_design`으로 해당 프로젝트의 인사이트를 읽습니다.
2. 디자인 선택·거절·개선 결과에서 재사용할 근거가 생기면 `capture_design_insight`로 적재합니다. 작업별 학습이 허용된 경우 별도의 ‘기억해줘’ 요청 없이 진행하며, 저장 금지 요청은 따릅니다.
3. 다음 작업에서 저장된 취향과 프로젝트 맥락을 반영합니다. 이전 인사이트를 고치거나 철회할 때는 같은 키와 현재 revision을 지정해 이력을 보존합니다.

기본 범위는 프로젝트 내부입니다. 여러 프로젝트에 공통 적용할 취향은 사용자가 직접 밝힌 경우에만 별도로 확인해 저장합니다. 추정한 취향은 검토 전까지 적용하지 않으며, 관찰 결과를 개인 성향이나 전역 규칙으로 바꾸지 않습니다.

개인 공간은 설치 캐시 밖에 보존됩니다. 플러그인 업데이트가 기존 저장소를 초기화하지 않고, Codex 메모리를 가져오지도 않습니다. 공개 패키지·PR에는 코드와 일반 지침·합성 예제만 포함합니다. 개인 인사이트·작업 본문·로그·캡처·계정 정보는 공개 자료에 넣지 않습니다.

자동 호출은 활성 스킬과 에이전트가 작업 흐름을 수행하는 방식입니다. 백그라운드 감시 서비스나 모든 디자인 결과의 자동 분류기를 추가한 것은 아닙니다. 실제 디자인에 취향이 반영됐는지는 결과물과 검토 근거로 확인해야 합니다.
