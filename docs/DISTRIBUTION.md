# Public source policy

This repository distributes plugin source and public templates. Keep personal runtime state outside this repository.

Never commit environment files, API keys, access tokens, private keys, personal Dictionary entries, collected article bodies, research runs, internal company evidence, browser profiles, recordings, local installation receipts, generated archives, dependency folders, or machine-specific registration files.

The public Radar catalog starts empty. KGJ includes design templates and examples, with personal Dictionary state kept outside the plugin. Canvas includes demo source and public reference assets; developer runtime recordings and local release evidence are excluded.

Public-source validation proves only its stated checks. Re-run tests when changing source, and record browser or Codex conversation verification separately. Do not relabel historical scores or installation receipts as evidence for new source.

The repository release tag identifies the full marketplace. Plugin manifests retain their individual versions. A new marketplace release never changes an existing tag.

Local stdio MCP is supported by this distribution; no remote server is supplied. Any future hosted variant needs its own deployment, authentication, user isolation, retention policy, and operating budget.

Code is distributed under MIT. Third-party documents, branding, and other referenced material retain their own rights. Preserve each plugin's attribution notices.
