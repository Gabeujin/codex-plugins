# v0.9.0 — KGJ Design 1.6.0 / FORM · TEN

작품을 설명하는 화면에서 직접 조작하는 전시로 발전시켰습니다. KGJ Design은 작품 중심 벤치마크 프롬프트 2.2.0, 작품별 마감 기준, 한국어 문안·조판 검토와 공식자료 우선 출처 정책을 제공합니다. 스킬은 13개이며 MCP 도구 14개와 기존 DNA·Dictionary 스키마, 기본 프롬프트·권한·외부 데이터 경로는 유지됩니다.

[FORM / TEN](../examples/form-ten/README.md)은 열 작품의 실행 가능한 소스입니다. 경복궁은 같은 2,327개 모형 부품을 확대·분해·그룹 정렬·아래부터 조립하는 60초 장면으로 구성합니다. 한글의 자모 합성, 실제 글꼴 굵기 비교, 개념 공간, 단계별 노트, 관측 영상의 렌즈, 검색에서 기록으로 이어지는 흐름, 결측을 보존하는 데이터 조형과 재질 실험을 서로 다른 조작으로 탐색할 수 있습니다. 작품별 재생 길이는 16–60초입니다.

공통 조작은 수동 편집 시 정지하고 장면 버튼·시간 막대와 동기화됩니다. 바로가기 링크의 작품 이동 오류, 검색 이력 복귀 후 오래된 응답, 키보드 편집·목록 포커스 유실, 확대 영상 가장자리의 중심 불일치, 대체 보기 초기화와 표면 줄무늬를 수정했습니다. 모형의 수량·치수는 문화유산 실측값이 아니며, 모델 호출과 서버 저장을 실행하지 않습니다.

자료는 공식·원본 출처부터 조사하고 근거가 부족할 때만 기록을 남겨 연구·공인 언론·위키백과, 이후 커뮤니티로 넓힙니다. 숨은 지시·역할 사칭·가짜 수치·출처 위조는 명령으로 채택하지 않으며 영향을 받은 주장은 독립 계보로 확인합니다. 이 정책과 정적 검사는 완전한 prompt-injection 차단을 인증하지 않습니다.

## 실행과 확인 범위

`node examples/form-ten/server.mjs` 실행 후 `http://localhost:4389/#/01`을 엽니다. 추가 의존성과 API 키가 필요하지 않습니다. 글꼴은 OFL, Webb 영상은 NASA·ESA·CSA·STScI 크레딧과 별도 이용 조건을 유지합니다.

저장소 회귀·패키지·격리 설치 검사와 실제 브라우저 검사를 구분합니다. `scripts/test-form-ten.mjs`는 1,440px·390px 및 13개 핵심 행동을 확인합니다. native OS IME·실물 터치·스크린리더·실제 BFCache 복귀는 별도 미확인입니다. 합성 pagehide/pageshow 검사를 native 복귀 증거로 표현하지 않습니다. 실제 장시간 재생 관찰은 seek 기반 CI 검사와 별도로 기록합니다.

이번 공개 소스 릴리스는 KGJ의 닫힌 15검사·3라운드·9.9 인증을 주장하지 않습니다. 해당 엄격한 인증에는 별도의 설치·신규 Codex 세션·종결 attestation이 필요하며, 기존 기준과 검증기는 유지됩니다. 테스트 캡처·개인 Dictionary·비공개 참고 페이지·대화·작업 경로·실행 영수증은 공개 패키지에서 제외했습니다. 전시 내 썸네일은 내비게이션 자산이며 검증 증거가 아닙니다.
