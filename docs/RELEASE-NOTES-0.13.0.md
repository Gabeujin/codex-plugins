# v0.13.0 — 확인할 수 있는 디자인 벤치마크

KGJ Design 1.9.0은 벤치마크를 요청할 때 작업 기록을 시작부터 추적하고 결과 화면에 표시하도록 안내합니다. 앱별 기획·설계·개발·완료 시각, 관찰된 모델과 입출력 토큰, 공식 단가에 따른 API 환산 비용을 기록합니다. 주요 화면의 Lighthouse 점수는 상세 결과·측정 시각·검사한 소스와 연결합니다.

확인할 수 없는 값에는 이유를 남깁니다. 공통 작업은 별도로 집계하며, 전체 토큰이나 시간을 앱 수로 나눠 채우지 않습니다. API 환산액과 실제 청구액도 구분합니다. 실제 기록은 활성 에이전트와 실행 환경이 제공해야 하며, 플러그인이 계정 사용량이나 과거 작업을 자동 관찰하는 것은 아닙니다.

UI/UX 자료가 필요할 때는 Forma의 레퍼런스와 용어 사전을 먼저 고려합니다. 필수 의존성은 아니며, 접근할 수 없거나 작업에 맞지 않으면 다른 근거를 사용합니다. 모델·요금·기술 사양 같은 사실은 담당 공식 출처로 확인합니다.

개인 Dictionary와 Codex 메모리는 가져오거나 변환하지 않습니다. 기존 Dictionary 1.0 저장 형식·위치와 개인 인사이트의 프로젝트 격리는 유지합니다. 공개 패키지에는 일반 구현·지침·새로 작성한 합성 입력만 포함합니다. 실제 작업 기록·개인 메모리·회사 자료는 배포 대상이 아닙니다.

K-Tech Radar 0.4.1, Canvas Web Experiences 1.7.0, Codex Daily Check 0.6.0은 변경하지 않습니다. 검사 도구의 통과는 기록의 진실성, 모든 환경의 접근성, 실제 청구액이나 모델 품질을 인증하지 않습니다.
