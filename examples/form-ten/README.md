# FORM / TEN — 감각의 구조

열 개의 인터랙티브 작품을 모은 로컬 전시입니다. Node.js 22 또는 24에서 이 폴더의 `node server.mjs`를 실행하고 [첫 작품](http://localhost:4389/#/01)을 엽니다. 외부 서비스나 npm 설치가 필요하지 않습니다. 이미 포트를 사용 중이라면 `PORT` 환경 변수로 다른 번호를 지정합니다.

| 작품 | 직접 해볼 것 | 재생 길이 |
|---|---|---|
| 01 지어진 시간 | 부품 선택·확대, 47초 전체 정렬, 아래부터 조립 | 60초 |
| 02 글자가 되는 순간 | 한글 한 글자 입력, 자모 분리와 합성 | 16초 |
| 03 관계의 장 | 점 추가·이동·연결·삭제·되돌리기, 방향키 편집 | 24초 |
| 04 편집하는 지면 | 문장·크기·자간·굵기 편집과 비교 | 18초 |
| 05 개념의 궤도 | 개념 표식 열기, 시점과 보기 크기 변경 | 36초 |
| 06 작업을 잇는 노트 | 작업 종류·문장 변경, 단계 확인·취소 | 30초 |
| 07 빛이 남긴 지형 | 원본 영역 선택, 렌즈와 네 모서리 탐색 | 30초 |
| 08 기록의 흐름 | 검색 → 기록에 담기 → 초안 편집 → 확인 | 18초 |
| 09 숫자의 풍경 | 월·계열 선택, 결측·합계·표 비교 | 24초 |
| 10 물성 스튜디오 | 도자·금속·유리, 광원·깊이·SVG 대체 보기 | 24초 |

처음과 마지막 장면은 정지 상태입니다. 재생·시간 막대·장면 버튼으로 이동하며, 수동 편집은 재생을 멈춥니다. 작품 목록과 상단 화살표로 이동할 수 있습니다. 모션 감소 설정은 자동 재생을 요구하지 않으며 같은 제어를 사용할 수 있습니다.

경복궁은 자체 제작한 설명용 모형입니다. 2,327개는 모형에 등록된 부품 수이며 실제 문화유산의 실측 수량이 아닙니다. 모델을 소개하는 작품은 공식 용도를 바탕으로 한 합성 예시이며 실제 모델을 호출하지 않습니다. 검색·노트·데이터도 로컬 합성 예시입니다.

코드와 새로 작성한 문안은 저장소의 MIT 라이선스를 따릅니다. 외부 글꼴·관측 영상은 [자산 및 출처](SOURCES.md)의 별도 조건과 크레딧을 유지합니다. 다른 창작자의 비공개 페이지, 개인 Dictionary와 대화 기록은 포함하지 않습니다.

`node build.mjs`는 실행 파일의 해시를 `build-id.json`에 기록합니다. 앱 소스가 곧 실행 빌드인 native ES modules입니다. [제작 프롬프트](prompt-v3.md)는 개발 기준이며 성능·디자인 우월성·정식 릴리스 PASS를 보증하지 않습니다.
