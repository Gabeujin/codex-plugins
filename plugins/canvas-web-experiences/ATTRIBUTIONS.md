이 플러그인은 외부 코드를 포함하지 않고 공개 문서·리포지터리를 요약하고 링크합니다. 소스별 라이선스는 채택 시 최신 원문을 다시 확인해야 합니다.

## Chrome 및 웹 표준 자료

- Chrome Developers 문서와 블로그: Google Developers Site Policies의 문서·샘플 조건을 따릅니다.
- GoogleChrome/modern-web-guidance: 문서 콘텐츠는 CC BY 4.0, 코드 샘플은 Apache-2.0으로 안내됩니다.
- WICG/WHATWG 자료: 각 리포지터리 및 표준 문서의 라이선스와 기여 정책을 따릅니다.

## 디자인 자료

- Toss Tech의 `deadend`, `interaction`, `toss-design-system-guide` 글은 작업 프로토타입, 상태를 설명하는 모션, 컴포넌트 거버넌스에 대한 1차 자료로만 요약했습니다. 문구·브랜딩·시각 스타일은 복제하지 않았습니다.

## 공개 프로젝트

카탈로그에 기록된 라이선스는 조사 시점의 공식 리포지터리 기준입니다. 특히 `tldraw`와 `CanvasUI`는 단순한 “MIT 라이브러리”로 취급하면 안 됩니다. tldraw는 자체 라이선스 조건을, CanvasUI는 사이트가 안내하는 MIT + Commons Clause 조건을 채택 전에 검토해야 합니다.

PixiJS, Phaser, Three.js, PlayCanvas, Paper.js, Excalidraw, deck.gl, luma.gl은 MIT 계열로 기록했고, Babylon.js와 CesiumJS는 Apache-2.0, MapLibre GL JS는 BSD-3-Clause로 기록했습니다. 버전이나 하위 패키지에 따라 조건이 달라질 수 있으므로 잠금 버전의 `LICENSE`를 최종 기준으로 삼습니다.

- 문서 문구와 예제 코드를 대량 복제하지 않습니다.
- 공식 API 이름, 호환성 상태, 아키텍처 원칙을 짧게 요약하고 원문 URL을 제공합니다.
- 프로젝트 도입 전에 라이선스, 유지보수 상태, 보안 공지, 브라우저 호환성을 다시 확인합니다.
