# Support policy

## Local and Git marketplace releases

Use the repository issue tracker for reproducible bugs and feature requests. Before publishing a repository, replace `REPOSITORY_URL` below with the final public URL:

- Issues: `REPOSITORY_URL/issues`
- Security reports: use the repository's private security-advisory flow, not a public issue.

Include plugin version, Node.js version, operating system, transport, affected tool, and a minimal reproduction. Remove credentials, personal data, private source text, and local paths.
