# 한국어 제품 문안과 조판 검토

독자가 내용을 이해하고 다음 행동을 고를 수 있도록 제품 문안과 읽기 흐름을 다듬는다.
제품의 동작, 원문의 뜻, 기존 용어와 말투를 먼저 확인한다.

## 필요한 자료만 읽기

- 새 문안, 문장 수정, 번역 검토에는 [문안 검토](references/korean-copy-review.md)를 읽는다.
- 글꼴, 줄바꿈, 배치 또는 실제 화면을 다루면 [조판 검토](references/korean-typography.md)도 읽는다.
- 글만 주어졌으면 문안과 배치 제안까지 다룬다. 렌더링을 확인하기 전에는 글꼴·잘림·접근성 검증을 완료했다고 하지 않는다.

## 진행 순서

1. 독자, 사용자의 과제, 표시 위치와 상태를 짧게 정한다. 이름·식별자·수치·단위·조건·부정·예외·인용을 보호한다.
2. 현재 문안과 실제 동작의 근거를 대조한다. 모르는 처리나 결과를 문장에 보태지 않고, 불명확한 부분은 확인 대상으로 남긴다.
3. 어휘의 뜻과 결합, 문장 성분의 호응, 수식 범위와 정보 순서를 고친다. 구조가 문제라면 동의어만 바꾸지 않는다. 수정할 이유가 없으면 유지한다.
4. 수정문만 읽어 이해되는지 확인한 뒤 원문·제품 근거와 다시 대조한다. 화면을 바꿨다면 관련 상태와 폭, 확대, 실제 글꼴에서 읽고 조작해 본다.

고친 문안을 먼저 제시하고 필요한 이유와 남은 확인 사항만 덧붙인다. 여러 필드는 위치와 상태를 함께 적는다.
규범 오류, 문맥 문제, 문체 제안, 미확인을 구분한다. 특정 낱말을 금지하거나 임의의 자연스러움 점수로 판단하지 않는다.

파일에 반영했다면 저장된 변경 문자열 전체를 의도한 문안과 정확히 대조한다.
문안 검토, 정적 검사, 렌더링과 실제 조작의 확인 범위를 각각 기록한다.
