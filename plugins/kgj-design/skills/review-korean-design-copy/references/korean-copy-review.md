# 한국어 제품 문안 검토

제목·레이블·버튼·상태·오류·짧은 설명을 새로 쓰거나 고칠 때 읽는다.
번역 원문이 있으면 함께 대조한다. 한국어만 있으면 원문을 추측하지 않고 제공된 문장의 문제를 설명한다.

## 뜻과 동작을 먼저 고정하기

독자에게 필요한 정보와 행동을 정하고 주체, 대상, 처리 시점, 결과를 확인한다.
이름, ID, URL, 인용, 수치·단위·정밀도, 날짜, 조건·예외, 부정의 범위와 가능성·의무의 강도를 지킨다.
일부·전체·최대·이전까지 같은 한정 표현을 줄이다가 사실의 범위를 바꾸지 않는다.
전부에 대한 부정을 특정 집단의 존재나 가능성을 확정하는 문장으로 바꾸지 않는다.

문안, 검토 중인 소스, 실행 화면과 과거 캡처의 버전·상태를 구분한다.
소스에 적힌 동작이 현재 화면에서도 실행됐다고 단정하지 않는다.
분기마다 결과가 다르면 공통으로 성립하는 행동을 쓰거나 조건을 드러낸다.
확인할 수 없는 기능, 오류 원인이나 효과를 읽기 좋은 표현으로 채워 넣지 않는다.

## 어휘와 문장 구조

| 관점 | 확인할 내용 |
| --- | --- |
| 뜻과 어휘 결합 | 단어가 실제 대상과 현상을 가리키는가? 목적어와 동사가 어울리는가? 전문 용어를 쉬운 말로 바꾸면서 개념을 잃지 않는가? |
| 성분과 호응 | 누가 무엇을 하는지 읽히는가? 주어·서술어와 조사, 병렬 항목의 관계가 맞는가? |
| 수식과 생략 | 수식어와 지시어의 대상이 분명한가? 문장 중간에 주체가 바뀌는데 생략돼 있지 않은가? |
| 조건과 논리 | 문장을 나누거나 순서를 바꿔도 부정·기한·예외·원인과 결과가 그대로인가? |
| 정보 순서와 말투 | 사용자가 알아야 할 행동과 결과가 보이는가? 추상 명사를 쌓거나 같은 서두·맺음말을 반복하지 않는가? 제품의 말투가 일관되는가? |

한자어, 외래어, 피동문이나 특정 서술어를 일괄 제거하지 않는다.
낱말만 바꿔도 추상적인 명사열이 남는다면 확인된 행동과 관계를 중심으로 문장을 다시 구성한다.
짧은 문장이 항상 더 명확한 것은 아니다. 중요한 조건을 빼거나 불필요한 질문·감정·효과 보증을 보태지 않는다.

번역은 원문의 어순보다 의미 관계를 따라 한국어로 다시 쓴다.
누락된 주체를 만들어 내지 않고 허용·가능성·권고·의무를 서로 바꾸지 않는다.
원문과 대조한 다음 한국어만 따로 읽는다. 역번역이나 자동 교정 결과만으로 정확성을 판정하지 않는다.
인용을 개작했다면 직접 인용으로 남겨 두지 않는다.

## 버튼과 상태 문구

버튼은 실제로 수행하는 행동을, 보조 설명은 필요한 조건과 결과를 나타낸다.
짧게 만들려고 행동의 대상을 지우지 않는다. 눈에 보이는 라벨을 접근 가능한 이름에도 포함하고 두 이름이 같은 행동을 가리키는지 확인한다.

입력 전, 처리 중, 부분 결과, 완료, 실패와 취소를 실제 상태에 맞춰 쓴다.
요청을 보냈다는 사실을 완료로, 취소 의사를 전달한 상태를 취소가 끝난 상태로 표현하지 않는다.
현재 화면을 닫는 동작과 진행 중 처리를 중단하는 동작도 구분한다.
실패 안내는 확인된 사실과 다음에 가능한 행동을 알려 준다. 이미 끝났을 수 있는 동작을 무조건 다시 실행하도록 권하지 않는다.
라벨 길이가 바뀌어도 제어 위치와 포커스, 상태의 의미가 유지되는지 화면에서 확인한다.

수량은 제품의 로캘과 표시 규칙을 따르고 부호·소수·단위를 보존한다.
한국어 수량의 정수 부분이 1,000 이상이면 쉼표로 묶되 연도·버전·전화번호·식별자는 같은 방식으로 바꾸지 않는다.
편집 가능한 수치의 표시를 바꾸면 파싱·검증·모바일 입력과 계산 값도 함께 확인한다.

## 사전과 근거의 사용

뜻·표기·어휘 결합이 의심되는 항목만 실제로 조회한다.
항목의 뜻, 문형과 용례를 문맥에 맞게 읽고 확인한 링크와 판단을 남긴다.
사전 첫 화면이나 검색 제목만 열어 놓고 항목을 검토했다고 하지 않는다.
등재 여부만으로 전문 용어의 적합성이나 문장 전체의 자연스러움을 판정하지 않는다.

## 마무리

수정문만 읽어 목적과 행동을 이해할 수 있는지 본 뒤, 원문·동작 근거와 보호 대상을 다시 대조한다.
중요한 변경은 위치, 문제, 채택 문안, 이유와 확인 상태를 짧게 남긴다.
화면을 보지 않았으면 문안 검토 결과만 기록하고 조판·키보드·접근 가능한 이름의 검사는 미실행으로 둔다.
